# Bukku releases

Signed and notarised Bukku downloads for macOS, and the Sparkle update feed.

- Download: [Releases](https://github.com/aleksgorbenko/bukku-releases/releases), or `brew install --cask gorbenko/tap/bukku`.
- About Bukku: [aleksgorbenko.dev/apps/bukku](https://aleksgorbenko.dev/apps/bukku/).
- `appcast.xml` is served at `https://aleksgorbenko.dev/apps/bukku/appcast.xml`; Bukku's release script updates it, never by hand.
